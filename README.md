# Brownstone 3D

Interactive 3D model and guided walkthrough of a brownstone renovation.

Open the live page: https://mshin99.github.io/brownstone/

- **Level** switches between cellar, basement, first and second floors, or the whole house.
- **Walkthrough** plays a guided tour at eye level with play, pause, reverse, fast-forward and jump-to-room controls.
- **Walk** buttons drop you into a room; drag to look, WASD or arrow keys to move.

Furniture and finishes outside the kitchen are placeholders.
